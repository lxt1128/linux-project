1. 系统概述
================================================================================

全场景错题管理系统是一个基于Shell的错题管理工具，支持错题录入、批量导入、
智能复习、统计分析等功能。

主要特性：
- 支持多科目错题管理
- 错误原因分析记录
- 艾宾浩斯遗忘曲线复习
- 批量导入/导出功能
- 智能标签分类系统

系统要求：
- Linux/Unix 系统
- Bash 4.0+
- 依赖包：jq, bc, cron

4. 核心模块详解
================================================================================

4.1 录入错题模块 (add_note.sh)
--------------------------------
功能描述：手动录入错题记录，支持详细信息填写。

使用方法：
./scripts/core/add_note.sh

输入字段：
- 科目名称：如 "数学"、"物理"、"化学"
- 错题内容：具体的问题描述
- 正确答案：标准答案
- 解题提示：解题思路或方法
- 标签分类：如 "基础", "难题", "计算", "概念"
- 错误原因：分析错误原因

示例交互：
请输入科目名称: 数学
请输入错题内容: 2x + 3 = 7, 求x的值
请输入正确答案: x = 2
请输入解题提示: 移项合并同类项
请输入标签(多个用逗号分隔): 代数,一元一次方程
请输入错误原因: 计算错误

4.2 批量导入模块 (import_note.sh)
----------------------------------
功能描述：从CSV/TXT文件批量导入错题记录。

使用方法：
方法1：通过主菜单导入
./start.sh  # 选择选项2

方法2：直接运行导入脚本
./scripts/core/import_note.sh

文件格式：
subject,question,answer,hint,tags,error_reason
数学,"2x+3=7求x","x=2","移项合并同类项","代数,方程",计算错误
物理,"牛顿定律","F=ma","力与加速度关系","力学",概念不清

字段说明：
- subject: 科目名称
- question: 错题内容
- answer: 正确答案
- hint: 解题提示
- tags: 标签（逗号分隔）
- error_reason: 错误原因

4.3 批量处理模块 (batch_process.sh)
------------------------------------
功能描述：对错题进行批量操作。

使用方法：
./scripts/core/batch_process.sh

批量操作类型：
1. 批量修改标签
2. 批量导出错题
3. 批量删除错题
4. 批量重置复习状态
5. 批量修改错误原因

操作示例：
请选择批量操作类型:
1) 批量修改标签
2) 批量导出错题
3) 批量删除错题
4) 批量重置状态
5) 批量修改错误原因
> 1

请输入要修改的科目: 数学
请输入新的标签: 基础,代数
确认批量修改? (y/n) y

4.4 编辑错题模块
------------------
功能描述：修改已有错题的详细信息。

使用方法：
./start.sh  # 选择选项3

操作流程：
1. 输入错题ID
2. 选择要修改的字段
3. 输入新的内容
4. 确认保存

4.5 复习错题模块
------------------
功能描述：按艾宾浩斯遗忘曲线安排复习计划。

使用方法：
./start.sh  # 选择选项5

复习算法：
- 新错题：1天后复习
- 已复习1次：3天后复习
- 已复习2次：7天后复习
- 已复习3次：15天后复习
- 掌握：30天后再次复习

4.6 统计报告模块
------------------
功能描述：生成学习统计报告。

使用方法：
./start.sh  # 选择选项6

统计内容：
- 各科目错题数量
- 错误原因分布
- 复习进度统计
- 掌握率分析

5. 批量导入操作
================================================================================

5.1 准备导入文件
------------------
CSV格式示例：
subject,question,answer,hint,tags,error_reason
数学,"因式分解 x²-4","(x+2)(x-2)","平方差公式","代数,因式分解",公式应用错误
物理,"动能公式","E=½mv²","质量和速度关系","物理,力学",公式记忆错误
化学,"水的分子式","H₂O","氢氧原子比例","化学,分子",概念混淆

TXT格式示例：
数学|因式分解 x²-4|(x+2)(x-2)|平方差公式|代数,因式分解|公式应用错误
物理|动能公式|E=½mv²|质量和速度关系|物理,力学|公式记忆错误

5.2 导入步骤
--------------
方法1：通过主菜单
1. 运行 ./start.sh
2. 选择 "2. 批量导入错题"
3. 输入文件路径（支持从电脑磁盘中导入）
4. 确认导入

方法2：直接导入（支持从电脑磁盘中导入）
./scripts/core/import_note.sh < /path/to/your/file.csv

5.3 导入验证
--------------
- 自动检查文件格式
- 验证必填字段
- 显示导入结果统计

8. 常见问题解答
================================================================================

Q1: 导入文件格式错误怎么办？
A: 检查CSV文件是否使用UTF-8编码，字段分隔符是否为逗号。

Q2: 如何查看所有错题？
A: 使用编辑功能，输入科目名查看该科目的所有错题。

Q3: 数据丢失如何恢复？
A: 检查 data/backups/ 目录，使用恢复脚本恢复数据。

Q4: 如何批量修改特定错题？
A: 使用批量处理功能，按标签或ID范围进行筛选修改。

Q5: 复习提醒不准确怎么办？
A: 检查系统时间设置，确保日期格式正确。
